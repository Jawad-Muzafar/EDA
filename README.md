# Exploratory Data Analysis (EDA) Projects

This repository is a beginner-friendly collection of Jupyter notebooks focused on Exploratory Data Analysis (EDA). EDA is the process of examining a dataset to understand its structure, discover patterns, identify missing values, and prepare the data for deeper analysis or machine learning.

## Purpose of this repository

The main purpose of this project is to help learners practice the basics of data analysis in a simple and clear way. It shows how to inspect data, ask useful questions about it, and use visualizations to better understand what the data is telling us.

## What is included

This repository contains separate notebooks for three well-known datasets:

- Heart Attack dataset
- Tips dataset
- Titanic dataset

Each notebook is designed to demonstrate how EDA is performed on a real dataset.

## What you will learn

By working through these notebooks, you will learn how to:

- load data into Python
- view the first few rows of a dataset
- understand the columns and data types
- check for missing values
- calculate basic descriptive statistics
- identify relationships between variables
- create plots such as histograms, bar charts, and scatter plots
- interpret the results of the analysis

## Typical steps in the notebooks

Each notebook usually follows a similar workflow:

1. Import the required libraries.
2. Load the dataset.
3. Explore the shape and structure of the data.
4. Check for missing or inconsistent values.
5. Summarize the key statistics.
6. Visualize important patterns and trends.
7. Draw simple conclusions from the findings.

## Technologies used

The notebooks use the following tools and libraries:

- Python
- Jupyter Notebook / JupyterLab
- pandas for data manipulation
- matplotlib for basic plotting
- seaborn for more attractive statistical visualizations

## How to use this repository

To use this project:

1. Install Python and Jupyter Notebook or JupyterLab.
2. Open the notebook you want to study.
3. Run the cells in order from top to bottom.
4. Read the explanations and observe the outputs.
5. Modify the code to experiment with the data on your own.

## Who this repository is for

This repository is useful for:

- beginners learning Python and data analysis
- students practicing EDA
- anyone who wants to understand how data is explored before modeling

## Note

This project is intended for educational purposes. It is a practical way to learn the fundamentals of data analysis and visualization.
