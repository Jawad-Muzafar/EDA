# Exploratory Data Analysis (EDA) Projects

This repository contains a polished collection of Jupyter notebooks focused on Exploratory Data Analysis (EDA). EDA is the process of examining and understanding a dataset by exploring its structure, identifying patterns, detecting missing values, and preparing the data for deeper analysis or modeling.

## Overview

The purpose of this project is to provide a practical and beginner-friendly introduction to data analysis. Through these notebooks, learners can observe how real datasets are inspected, summarized, and visualized step by step.

## Included Datasets

This repository includes hands-on notebooks for the following datasets:

- Heart Attack Dataset
- Tips Dataset
- Titanic Dataset

Each notebook demonstrates how EDA is applied to a real-world data problem.

## Learning Objectives

By working through these notebooks, you will learn how to:

- load and inspect datasets in Python
- understand dataset structure and column types
- check for missing or inconsistent values
- calculate descriptive statistics
- identify relationships between variables
- create informative visualizations
- interpret findings and draw meaningful conclusions

## Typical Workflow

Each notebook follows a clear and structured workflow:

1. Import the required libraries.
2. Load the dataset.
3. Explore the shape and basic characteristics of the data.
4. Check for missing values and data quality issues.
5. Summarize the main statistics.
6. Visualize patterns and trends.
7. Interpret the results and document insights.

## Tools and Libraries

The notebooks are built using:

- Python

- matplotlib for static visualizations
